# BookFry Mascot Prompt Library

Generate one mascot at a time. Keep the existing BookFry navy (#163A63),
orange (#F97316), and white branding. Modern, premium, friendly,
memorable, no childish clipart.

## Global Rules

-   Transparent background
-   3D/Pixar-quality or premium vector
-   Consistent character proportions
-   Expressive eyes
-   Front, side, back, and 3/4 views
-   Reading, searching, selling, celebrating, thinking, delivering,
    studying poses
-   Export as SVG-style vector look and high-resolution PNG
